一个地牢探险类型小游戏，具有一定rpg元素、大地图探索功能的demo。

游戏中有多个不同层数的地下城，地下城类型不同，其中的怪物类型也不同。
每一层地牢都有一个可恢复生命值和精力值的圣泉，以及一个可以传送到地下城外面的传送门，从地下城外面也可以通过这个传送门到达所有到达过的层数。

具有快速旅行功能，可以通过大地图移动到已经去过的地图。
